# Prepaid Recharge & Tariff Calculator

A program for managing prepaid mobile customers, recharges, and usage. It supports call, SMS, and data usage, balance checks, tariff clculations, and bundle pricing.

### Sample Inputs

- Customer name: Asha
- MObile number: 9876543210
- Recharge amount: 500
- Call duartion: 10 minutes
- SMS count: 5
- Data usage: 100 MB

## Build 
```bash
dotnet build
```

## Run
```bash
dotnet run
```
